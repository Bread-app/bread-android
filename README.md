# Bread for Android

Android build of Bread for Google Play and the **Solana dApp Store** (Seeker).
It is forked from `bread-mobile` (Expo 54 / React Native 0.81, Expo Router,
Privy) and shares the same backend (`stock-backend`).

Built to the Solana Mobile docs: https://docs.solanamobile.com/llms.txt

## What's Android-specific

| Area | Where | Notes |
| - | - | - |
| Mobile Wallet Adapter | `src/components/solana-mobile-provider.tsx` | `@wallet-ui/react-native-web3js` `MobileWalletProvider`, mainnet. It sits above `BottomSheetModalProvider` so sheets can use `useMobileWallet`. |
| MWA auth cache | `src/lib/solana-mobile/secure-store-cache.ts` | SecureStore instead of the default unencrypted AsyncStorage. |
| App identity | `src/lib/solana-mobile/identity.ts` | `uri: https://breadapp.fun`, relative `icon`. Verified through Digital Asset Links. |
| Wallet sign-in | `src/hooks/use-solana-wallet-login.ts` | MWA signs a Privy SIWS message. Privy stays the identity provider, so backend JWT auth is unchanged. |
| Deposit from on-device wallet | `src/hooks/use-mwa-usdc-deposit.ts` | Add cash → "Wallet on this phone": one MWA prompt sends USDC to the user's Bread wallet. |
| Seeker detection | `src/lib/solana-mobile/seeker.ts` | Checks `Platform.constants` (can be spoofed, so UI only). Anything of value must verify the Seeker Genesis Token on the server. |
| Crypto polyfill | `polyfill.js`, first import in `entrypoint.js` | `react-native-quick-crypto` `install()`, as the MWA setup docs require. |
| dApp Store | `dapp-store/README.md`, `eas.json` → `dapp-store` | Signed APK, separate signing key, publishing CLI. |

Removed from the iOS app: Apple sign-in, the iOS Notification Service Extension,
and Apple Pay copy (the on-ramp is shown as "Card"). The iOS 26 Liquid Glass and
SwiftUI components are still in the code, but they fall back to plain RN views
on Android.

## Setup

MWA uses native Kotlin modules, so **Expo Go does not work**. Use a dev build.

```bash
npm install
npm run build:dev            # EAS dev-client APK, install it on the device
npx expo start --dev-client
```

Local native builds (`npm run android`) need JDK 17 and the Android SDK.
`android/` is generated by `expo prebuild` (Continuous Native Generation) and is
gitignored. Change native config in `app.json`, not in `android/`.

To test wallets, install an MWA wallet on the device or emulator: Seed Vault on
Seeker, or Phantom / Solflare. For an emulator, see
https://docs.solanamobile.com/get-started/development-setup.

## Environment

The same variables as bread-mobile are set per profile in `eas.json` (gitignored):

```bash
EXPO_PUBLIC_API_URL=https://bread-be.vercel.app
EXPO_PUBLIC_PRIVY_APP_ID=...
EXPO_PUBLIC_PRIVY_CLIENT_ID=...
EXPO_PUBLIC_SOLANA_RPC_URL=...        # optional, MWA blockhash only; defaults to public mainnet
EXPO_PUBLIC_DISTRIBUTION=dapp-store   # set by the dapp-store profile
```

## Builds

| Script | Profile | Output |
| - | - | - |
| `npm run build:dev` | development | debug dev-client APK |
| `npm run build:apk` | preview | internal release APK |
| `npm run build:play` | production | .aab for Google Play |
| `npm run build:dapp-store` | dapp-store | signed APK for the Solana dApp Store |

## Required one-time config

1. **Privy dashboard**: enable **Solana wallet (SIWS)** login and add the
   Android package `com.breadapp.fun` as an allowed app, or "Continue with
   Solana wallet" will be rejected.
2. **Digital Asset Links**: set `ANDROID_SHA256_CERT_FINGERPRINTS` on the
   bread-landing Vercel project. See `dapp-store/README.md` §2.
3. **dApp Store signing key**: `./scripts/create-dapp-store-keystore.sh`.
